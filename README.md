# ReqRes API Tests

Простой проект тестов для ReqRes API. Сделано в стиле новичка.

## Как запускать
1. Установить зависимости:
pip install -r requirements.txt
2. Запустить:
pytest
3. Отчёт:
allure serve reports/allure

- Создание пользователя
- Чтение
- Обновление
- Удаление

Проверки через простые assert и базовый logger.
